# Guia do Usuário - Pais

## Introdução

Bem-vindo ao Meu Lanche Digital! Este guia irá ajudá-lo a utilizar todas as funcionalidades disponíveis para pais e responsáveis.

## Funcionalidades Principais

### 1. Dashboard
- Visão geral do saldo dos filhos
- Histórico recente de compras
- Alertas e notificações importantes

### 2. Gerenciamento de Créditos
- Adicionar créditos à conta dos filhos
- Definir limites diários de gastos
- Visualizar histórico de recargas

### 3. Gerenciamento de Filhos
- Adicionar/remover filhos
- Configurar permissões individuais
- Visualizar QR Code de cada filho

### 4. Acompanhamento de Consumo
- Histórico detalhado de compras
- Relatórios de gastos
- Alertas de consumo

## Como Usar

### Adicionando Créditos
1. Acesse o menu "CredLanche"
2. Selecione o filho
3. Digite o valor desejado
4. Confirme a transação

### Configurando Limites
1. Vá para "Gerenciar Filhos"
2. Selecione o filho
3. Defina o limite diário
4. Salve as alterações

### Visualizando Histórico
1. Acesse "Consumo"
2. Selecione o período desejado
3. Filtre por filho (opcional)
4. Visualize os detalhes

## Dicas e Boas Práticas

1. **Monitoramento Regular**
   - Verifique o saldo regularmente
   - Acompanhe o histórico de compras
   - Configure notificações importantes

2. **Segurança**
   - Mantenha sua senha segura
   - Não compartilhe o QR Code
   - Ative a autenticação em duas etapas

3. **Economia**
   - Defina limites realistas
   - Acompanhe os gastos
   - Configure alertas de saldo baixo

## Solução de Problemas

### Problemas Comuns

1. **Não consigo adicionar créditos**
   - Verifique sua conexão
   - Confirme se o pagamento foi processado
   - Entre em contato com o suporte

2. **QR Code não funciona**
   - Verifique se está atualizado
   - Tente gerar um novo código
   - Contate a cantina

3. **Saldo incorreto**
   - Verifique o histórico
   - Confirme as transações
   - Reporte ao suporte
